# v1.15.1 — Cold Start filtering and compatibility fixes

- Normal Reflection search and Cold Start now exclude Reflections whose source
  memories are retracted or superseded; audit counts report the filtered items.
- Pinned memories remain authoritative in the `pinned` section. Confirmed Core
  memories enter `identity_snapshot` only when they are not pinned, preserving
  compatibility with clients that read the legacy bucket.
- The `--wakeup-text` session-start path now includes the same compact Reflection
  block and policy as MCP wakeup.
- Salience review candidates require confirmed epistemic status before they are
  suggested.
