# v1.14.2 — Reviewable recall metadata reconciliation

## Added

- `reconcile_recall_metadata`, a maintenance tool that defaults to a dry-run
  plan. It identifies source memories whose non-abandoned Reflections contain
  explicit `open_questions`.
- Explicit application requires `dry_run=false` and a caller-supplied
  maintenance ID. The operation is recorded for audit and is idempotent per ID.
- The plan separates three categories:
  - Reflection-question updates that may be applied;
  - salience suggestions that always require manual review;
  - unresolved-language markers in memory text that are review leads only.

## Safety boundary

Anchor never infers `unresolved` or salience from prose and writes it
automatically. Only an already-saved, non-abandoned Reflection question can be
synchronized to its exact source event. The tool never changes memory text,
truth status, memory layer, or salience.
