# v1.15.0 — Structured cold-start packet

`wakeup` now exposes a stable, versioned Cold Start Packet without breaking the
existing bucket fields.

- Confirmed Core memories have a dedicated `identity_snapshot` section, so
  identity and relationship context does not depend on recency.
- Normal memory sections are mutually deduplicated. The contract maps them to
  Identity Snapshot, Active State, Key History, and Change Log.
- The legacy neutral salience value (`0.5`) is no longer presented as high
  salience. `salience_status` makes unreviewed data visible, while reconciliation
  emits deterministic Core/pin/Reflection review candidates without applying
  scores automatically.
- Draft Reflections are excluded by default. `include_draft_reflections=true`
  opts in explicitly, and `reflection_policy` reports the active policy.
- Cold-start Reflections are compact summaries instead of full source,
  counterevidence, and decision graphs.
- Added `n_identity`, `n_reflections`, and `include_draft_reflections` to the
  authoritative MCP schema.

The release does not infer unresolved state from prose and does not mutate
existing salience values.
