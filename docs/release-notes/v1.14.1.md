# v1.14.1 — Versioned discovery and recall regression boundaries

## Fixed

- HTTP discovery now copies tool description, input schema, annotations, and
  metadata from the same authoritative manifest used by stdio.
- Every advertised tool includes `_meta["anchor/schema_version"] = "1.2"`, so
  clients can detect a stale cached tool snapshot.
- The server version is now defined once rather than embedded in the stdio
  initialization response.

## Added

- Cross-transport tests verify every remotely exposed tool matches its
  authoritative manifest entry field-for-field.
- Recall regression coverage for family-context prioritization, ambiguous short
  replies, explicit memory questions, and the three-query recall limit.
- Model-facing instructions now prohibit short ambiguous replies from silently
  overwriting durable context and require searching before claiming memory.

## Deliberately unchanged

- The remote HTTP server still exposes a safer subset of legacy stdio
  maintenance tools. The contracts are unified; the allowed remote surface is
  intentionally narrower.
- No Drive State, autonomous desire system, reinforcement learning, personality
  mutation, or fully automatic Reflection was added.
